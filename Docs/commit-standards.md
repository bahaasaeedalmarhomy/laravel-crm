# Commit Standards

- feat:
  Use when adding a completely new animation, scene, or learning project.
    - *Example*: `feat: add Pythagoras theorem visual proof`
- fix:
  Use when fixing a broken animation, a Manim syntax error, or a rendering issue.
    - *Example*: `fix: correct the coordinates for the hypotenuse line`
- refactor:
  Use when you clean up or reorganize you code without changing the actual animation output (like grouping code into functions or classes)
    - *Example*: `refactor: extract square generation into a seperate function`
- docs:
  Use when updating README, adding study notes, or heavily commenting the code to remember how a Manim feature works.
    - *Example*: `docs: add notes on how ValueTracker works`
- chore:
  Use for environment setup, updating `.gitignore`, installing packages, or organizing project structure.
    - *Example*: `chore: move virtual environment to project root`
- practice:
  Use when beginning to experiment new features in Manim
    - *Example*: `study: experiment with Updaters in Manim`
